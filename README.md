# Teclado Virtual com Gestos

Um teclado virtual para Windows com suporte a interação por gestos, desenvolvido para proporcionar uma experiência prática e moderna de digitação.

## 🚀 Aplicativo

O **Teclado Virtual com Gestos** foi desenvolvido para facilitar a interação com o computador por meio de um teclado virtual e recursos de gestos.

### ✨ Recursos

* ⌨️ Teclado virtual
* 👋 Controle e interação por gestos
* 🖥️ Compatível com Windows
* ⚡ Interface simples e prática
* 🎯 Desenvolvido para facilitar a interação com o computador
